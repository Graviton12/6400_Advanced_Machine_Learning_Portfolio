3.1 Paper Overview of Simulation Study (Bates 2023)

This section summarizes the simulation study discussed in Cross-validation: what does it estimate and how well does it do it?, (Bates and Tibshiran 2023).

  • Title: Cross-validation: what does it estimate and how well does it do it?
  • Author: Stephen Bates, Trevor Hastie, and Robert Tibshiran
  • Journal: Journal of the American Statistical Association

3.1.1 The Big Picture: What is This Paper About?

  • Imagine you train a machine learning model on a specific set of data you collected today. You use 10-fold cross-validation to check its accuracy and put a \(90\%\) confidence interval around that error rate.Most people assume CV tells them: “Here is how well this exact model will perform on future data.”
  • The authors prove two main points:
    • Wrong Target: CV does not estimate the error of the exact model you just built (\(Err_{XY}\)). Instead, it estimates the average error (\(Err\)) of models trained on random datasets drawn from the same population.
    • Intervals are Too Optimistic: The standard way of calculating confidence intervals for CV assumes fold errors are independent. Because data points are reused across folds, they are actually correlated, making the estimated variance too small and confidence intervals too narrow (leading to undercoverage).
    • The Solution: The authors introduce Nested Cross-Validation (NCV) to accurately estimate the sampling variance and construct valid confidence intervals.

3.1.2 The Core Misconception: What is Cross-Validation Actually Measuring?

  • What people think happens: When you train a computer model on a specific dataset, you want to know how accurately that specific model will perform on brand-new, unseen data. People use a common tool called cross-validation (and related methods like data splitting, bootstrapping, or Mallows \(C_p\)) believing it estimates the error rate of their specific model.
  • What actually happens: The authors prove mathematically (specifically for a standard statistical technique called Ordinary Least Squares linear regression) that cross-validation does not tell you the error rate of your specific model.
  • The reality: Instead, it estimates the average error rate you would get if you trained many similar models on different, hypothetical datasets drawn from the same overall population

3.1.3 The Problem with Confidence Intervals: Unreliable Safety Margins

  • The Flaw: When scientists calculate a “confidence interval” (a range of numbers showing how confident they are in the error rate), standard cross-validation gives ranges that are far too narrow.
  • Why it breaks: Cross-validation reuses the same data points for both training and testing the model across different steps. Because data points are recycled, the measurements are correlated with one another. Standard statistical formulas assume these measurements are completely independent, causing them to vastly underestimate uncertainty and give a false sense of accuracy.

3.1.4 A Key Warning for Simple Data Splitting

  • Common Practice: A common trick when splitting data into “training” and “testing” sets is to evaluate the model on the test set, and then re-train (re-fit) the model on all the data combined to make it stronger.
  • The Takeaway: The authors warn that if you re-train the model on the combined data, your confidence intervals for accuracy become invalid and untrustworthy.

3.1.5 Author’s Proposed Solution:

  • The Fix: The authors invent a modified method called nested cross-validation to measure the uncertainty properly.
  • The Result: Through experiments, they show that this new method produces realistic confidence intervals that accurately capture the true range of prediction error in cases where standard cross-validation fails.

3.2 Key Concepts & Equations Explained:

3.2.1 Hyperparameter Tuning:

  • Hyperparameter tuning refers to the action of choosing and fine-tuning parameter values for a given model that result in the minimal error / highest accuracy.

3.2.2 Nested Cross Validation:

  • Outer Loop (Error Estimation):
    • The total original dataset is split into \(N\) number of outer folds where each fold is comprised of the training set and testing set.
    • The test set is held out exclusively for final model performance evaluation
  • Inner Loop (Hyperparameter Tuning):
    • Take the training set from the outer loop and split it further into an inner training subset and a validation set.
    • The training subset in run on the model and then evaluated on the validation set.
    • The model trains on the inner training subset across candidate hyperparameter values (these are the parameters we choose) and evaluate them on the inner validation set.
  • Hyperparameter Tuning (Select Optimal Hyperparameters):
    • Compute the inner validation accuracy for each hyperparameter configuration and choose the parameter setting that minimizes error / maximizes accuracy for a given iteration.
    • We take the chosen parameters plus the entire training set as a whole then we run on the test set and evaluate its performance.
  • Error estimation:
    • We take the average error on the training data
    • We take the average error on the testing data
    • This gives us the overall generalization error
  • Example:
    • Assume we have 3-Fold CV with some hyperparamter C for some values 1 and 2 for some model.
    • Further assume we have 3 observations (P1, P2, P3) in a dataset.
    • We want to optimize the hyperparamter C.
    • In this consider we only consider one inner loop for the 1st outer fold.
    • We determine which combination yielded the highest accuracy / minimized error.

3.2.3 Out-of-Sample Error Targets:

  • \(Err_{XY}\) (Instance-Specific Error): The expected error of the specific model trained on your observed data \((X, Y)\) when tested on unseen future data \((X_{n+1}, Y_{n+1})\):\[Err_{XY} := \mathbb{E}[\ell(\hat{f}(X_{n+1}, \hat{\theta}), Y_{n+1}) \mid (X, Y)]\]

  • Translation: \(\hat{f}\) is your fitted model with parameters \(\hat{\theta}\). \(\ell(\cdot, \cdot)\) is the loss function (e.g., squared error or binary classification loss). \(Err_{XY}\) is a random variable because it depends on the exact training dataset \((X, Y)\) you happened to collect.

  • \(Err\) (Average Error): The average error of models fitted on many hypothetical datasets drawn from the same population \(P\): \[Err := \mathbb{E}[Err_{XY}]\]

  • \(Err_X\) (Conditioned on Features): The expected error given the feature matrix \(X\), averaging over responses \(Y\): \[Err_X := \mathbb{E}[Err_{XY} \mid X]\]

3.2.4 Cross-Validation Point Estimate & Naïve Standard Error:

  • When splitting data into \(K\) folds, the \(K\)-fold CV estimator is: \[\widehat{Err}^{(CV)} := \bar{e} = \frac{1}{n} \sum_{i=1}^n e_i\]

  • where \(e_i\) is the loss on data point \(i\) when tested against a model fit on all folds except the one containing \(i\).

  • The standard (“naïve”) confidence interval relies on: \[se := \frac{1}{\sqrt{n}}\sqrt{\frac{1}{n-1}\sum_{i=1}^n (e_i - \bar{e})^2}\] \[\text{Interval} = \left(\widehat{Err}^{(CV)} - z_{1-\alpha/2} \cdot se, \; \widehat{Err}^{(CV)} + z_{1-\alpha/2} \cdot se\right)\]

  • Why it fails: This formula assumes \(e_i\) are independent. But because folds share overlap in training data, the errors \(e_i\) are correlated (producing non-zero covariances across folds, as shown in the block-diagonal covariance matrix). Thus, \(se\) underestimates the true variance, yielding intervals that are far too small.
